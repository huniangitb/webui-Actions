## 二十四、导航栏固定不动，不跟随键盘

### 修改
**文件**: `src/scss/_modal.scss`

删除 `body.keyboard-open .mx-subpage-footer` 规则，footer 保持 `transform: translateY(0)` 不变。

同时删除 `body.keyboard-open .mx-subpage-body, body.keyboard-open .overflow-y-auto` 的 padding-bottom 变化，因为 footer 不再移动，不需要额外 padding。

```scss
// 删除以下两段：
body.keyboard-open .mx-subpage-body,
body.keyboard-open .overflow-y-auto {
    padding-bottom: calc(var(--keyboard-h, 0px) + 90px) !important;
}

body.keyboard-open .mx-subpage-footer {
    transform: translateY(calc(-1 * var(--keyboard-h, 0px))) !important;
}
```

### 验证
- 键盘弹出时 footer 固定在底部不动
- 键盘覆盖在 footer 上方
- 内容区通过 scrollToInput 保持输入框可见
